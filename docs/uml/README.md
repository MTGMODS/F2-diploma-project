# UML — модель прецедентів

- [Редагована UML-модель](use-cases.uxf) — відкривається в UMLet 15.1.
- [PNG-експорт із CASE-редактора](../diagrams/use-cases.png).
- [Табличні специфікації UC-01/UC-02](../2_design.md#26-моделювання-користувацького-досвіду-та-транзакційних-сценаріїв).

Використано безкоштовний спеціалізований UML CASE-редактор UMLet; Mermaid для цієї діаграми не застосовується. Модель містить Subject/System Boundary, людські ролі, зовнішні системи, напрямлені асоціації, узагальнення, include, extend та зовнішню залежність переходу до каналу придбання. Включення й розширення мають напрям від базового прецеденту до включеної поведінки та від розширення до базового відповідно.

Користувач і адміністратор успадковують доступні публічні можливості; це не автоматичне підвищення ролі чи доступу. Готовий SA-MP-продукт є зовнішнім програмним актором, а RabbitMQ, сервіси й БД — внутрішніми компонентами платформи. Розроблення ігрової логіки готового продукту не входить до Subject.

PNG експортується з тієї самої UXF-моделі засобами UMLet. Первинним редагованим артефактом є UXF; зміни геометрії та зв’язків потрібно повторно експортувати. [Офіційний UMLet](https://www.umlet.com/) і [завантаження standalone](https://www.umlet.com/changes.htm).
