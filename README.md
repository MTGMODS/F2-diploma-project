# F2 Diploma Project

Робочий репозиторій кваліфікаційного проєкту бакалавра зі спеціальності F2
«Інженерія програмного забезпечення» (попередній шифр 121), Чернівецький
національний університет імені Юрія Федьковича.

Поточний навчальний етап — лабораторна робота №5 з дисципліни «Технічне
документування та презентація програмних рішень». Репозиторій містить
матеріали аналізу, планування та проєктування нової платформи, які надалі доповнюватимуться описом реалізації та результатами перевірки.
Предмет роботи — **micro-SaaS-платформа** для інфраструктурного супроводу раніше створеного зовнішнього цифрового продукту, а не розроблення самого продукту. Прикладом інтеграції є
наявний програмний помічник для гравців SA-MP.

У проєктному сценарії власник уже готового продукту замовляє окрему платформу для його представлення, розповсюдження та керування доступом. Попередня монолітна система використовується як джерело вимог: з неї визначаються функції та правила, які потрібно зберегти, зокрема формат ліцензійних ключів і прив’язування Telegram, Discord або обох облікових записів. Предмет роботи — **micro-SaaS-платформа**, а не розроблення самого ігрового помічника. Micro-SaaS описує вузькоспеціалізований сервіс, а мікросервісна архітектура — спосіб побудови платформи.
